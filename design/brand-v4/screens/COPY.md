# 화면 문구 (v4)

말투: 짧은 해요체. 확인한 사실을 먼저 말하고 다음 행동을 제안한다. 기다리는 사람에게 죄책감을 주지 않는다. 사람이 확인하기 전에 확정됐다고 말하지 않는다.

화면마다 큰 제목 한 줄은 "지금 상태"를 문장으로 쓴다. 모임 이름("현호님의 모임")은 제목 위 작은 머리말로 내린다.

## 첫 화면 (`/`)

| 자리 | 문구 |
|---|---|
| 큰 제목 | 친구들 약속, 링크 하나로 정해요 |
| 설명 | 단톡방에 링크만 보내면 돼요. 앱 설치도, 가입도 없어요. |
| 장면: 현호 말 | 이번 주 저녁 언제 돼? 여기 남겨 줘! |
| 장면: 링크 카드 | 현호님의 모임 · 되는 시간을 남겨 주세요 · 모여락 |
| 장면: 답 | 남겼어! · 나도 칠했어. 토요일 좋아 |
| 장면: 결과 | 11월 8일 (토) 오후 6시 · 녹사평역 · 모두 응답하고 현호님이 확정했어요 |
| 주 버튼 | 모임 만들기 |

## 모임 홈

| 상태 | 머리말 | 큰 제목 | 마주 안내 줄 | 주 버튼 |
|---|---|---|---|---|
| 아무도 응답 안 함 | 현호님의 모임 | 아직 아무도 응답하지 않았어요 | 첫 번째로 남겨 볼까요? | 가능한 시간 남기기 |
| 일부 응답 | 현호님의 모임 | 5명 중 4명이 응답했어요 | 민지님만 남았어요. 지금 결과로 제안 받아 볼까요? | 제안 받기 |
| 전원 응답 | 현호님의 모임 | 5명 모두 응답했어요 | 제안 받아 볼까요? | 제안 받기 |
| 장소 단계 | 현호님의 모임 | 시간은 정해졌어요. 이제 장소예요 | 출발지를 남기면 가운데 역을 찾아 드려요 | 출발지 남기기 |
| 확정 | 현호님의 모임 | 11월 8일 토요일, 녹사평역 | 약속이 정해졌어요 | 약속 카드 보기 |
| 참여 전(다른 사람) | 현호님의 모임 | 현호님이 약속을 잡고 있어요 | 이름을 남기고 함께 정해요 | 참여하기 |

보조 행동(글자 버튼): 재촉하기, 친구에게 링크 보내기.

## 시간 투표

| 자리 | 문구 |
|---|---|
| 큰 제목 | 언제 되세요? |
| 설명 | 되는 시간을 손가락으로 쓸어 칠해 주세요 |
| 말로 입력 자리 표시 | 담주 평일 저녁 되고 수요일은 빼줘 |
| 말로 입력 버튼 | 칠해 보기 |
| 말로 입력 결과 | 6칸을 칠했어요. 맞으면 저장해 주세요 · 되돌리기 |
| 말로 입력 실패 | 잘 못 알아들었어요. 시간표에서 직접 골라 주세요 |
| 탭 | 시간 고르기 · 최적일정 |
| 주 버튼 | 이 시간으로 저장 · 6칸 |
| 확정 뒤 | 이미 시간이 정해졌어요. 모임 홈에서 확인해 주세요 |
