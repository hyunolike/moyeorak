# 로고와 마주 승인 기록

- 날짜: 2026-11-01
- 승인: 호스트 (첫 번째 승인 지점)

## 고른 것

- 심볼: 환승역, 대칭 배치 (`logo/final/symbol.svg`). 양쪽 노선이 같은 높이에서 들어와 한 역에서 만난다. 어긋난 배치 두 가지(왼쪽 위, 오른쪽 위)는 ㄱ이나 "구"로 읽혀 쓰지 않는다. 생성기의 `arms` 인자로만 남겼다.
- 워드마크: `logo/final/wordmark.svg`. 정원 ㅇ, 자모 너비 36, 받침 노선과 역 점만 기준선 아래.
- 마주: 일곱 표정(`maju/`)과 띠 없는 소형(`maju/small/`). 성격 문장은 `maju/NOTES.md`.
- 조합: 가로, 세로, 단색 가로, 앱 아이콘, 16px 전용 심볼.

## 지나온 길

1. Codex 1회차: A(둥근), B(각진, 노선 받침), C(글자 속 마주) 세 안. 마주 얼굴이 심볼이었다.
2. Codex 2회차: B 다듬기, 마주에 노선 띠, 미안함과 기다림 표정 수정.
3. Codex 3회차: 배민과 토스 관점 평가 뒤 심볼과 마주 분리. 노선 하나짜리 심볼, 마주 상황 표정 두 개 추가, 소형 판.
4. 손 보정(Claude): 동아리 디자이너 관점 평가 뒤 심볼을 환승역으로, 락 높이 정렬, 마주 눈 확대와 띠 고리.
5. 손 보정(Claude): 레터링 규칙으로 워드마크 다시 그림. 둥근 네모 ㅇ이 ㅁ으로 읽혀 "모며락"이 되던 결함 수정.

## 호스트가 요청한 수정

- 유명 디자이너 관점 평가 → B안 방향으로 수정
- 배민과 토스 관점 평가 → 로고 심볼과 캐릭터 분리
- 넥스터즈와 디프만 관점 평가 → 직접 다듬기
- 로고 전문 업체 관점 → 한글 워드마크 개선
- 심볼 배치는 추천(대칭)으로 확정
