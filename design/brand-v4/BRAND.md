# 모여락 Brand v4

> 단톡방에 링크 하나, 약속은 하나로.

v3가 AI가 만든 서비스처럼 보인다는 판단에서 다시 세운 브랜드다. 결정 과정은 `logo/DECISION.md`와 `screens/DECISION.md`, 설계는 `docs/superpowers/specs/2026-11-01-design-system-v4-design.md`에 있다. 토큰의 정본은 `tools/build-tokens.mjs`이고, 이 문서의 색 값은 그 생성기와 같아야 한다(테스트로 확인한다).

## 1. 전략

모여락은 친구들이 단톡방에 링크 하나를 돌려 시간과 장소를 정하는 서비스다. 앱 설치도 가입도 없다. 마주가 응답을 보고 한두 개를 제안하고, 마지막 결정은 모임을 만든 사람이 한다.

방향은 놀(NOL)과 여기어때처럼 색과 표정이 살아 있는 쪽이다. 다만 장식으로 기분을 내지 않는다. 또렷한 글자 크기 차이, 아껴 쓰는 강한 색 하나, 목록과 여백으로 만든 구조로 낸다.

## 2. 로고

| 구성 | 파일 | 규칙 |
|---|---|---|
| 심볼 | `logo/final/symbol.svg` | 마주 얼굴(노선 띠 있는 일반 판) |
| 16px 심볼 | `logo/final/symbol-16.svg` | 띠 없는 마주 소형판. 브라우저 탭 전용 |
| 워드마크 | `logo/final/wordmark.svg` | 한글 "모여락". "락"의 받침 ㄱ이 노선이 되어 탠저린 역 점에 닿는다 |
| 가로, 세로 조합 | `logo/final/horizontal.svg`, `vertical.svg` | 심볼 + 워드마크 |
| 단색 | `logo/final/horizontal-mono.svg` | 잉크 한 색. 눈과 입, 역 점은 뚫는다 |
| 앱 아이콘 | `app/public/brand/icons/*` | 흰 바탕에 탠저린 마주 |

- 최소 크기: 가로 조합은 높이 24px, 심볼은 16px(16px은 전용판).
- 여백: 심볼 높이의 1/4을 사방에 비운다.
- 워드마크 레터링: ㅁ, ㅇ, ㄹ 너비 36, "여"의 ㅇ은 정원(둥근 네모는 작은 크기에서 "며"로 읽힌다), 세 글자 위끝과 몸통 아래끝이 같고 받침 노선과 역 점만 기준선 아래로 내려간다.
- 금지: 탠저린 바탕에 탠저린 마주(얼굴이 묻힌다), 잉크 바탕에 마주(노선 띠가 묻힌다), 워드마크 늘이기와 기울이기, 탠저린 위 흰 글자.

| 단계 | 값 | 쓰는 곳 |
|---|---|---|
| 50 | `#FFF4EC` | 마주 안내 줄 바탕 |
| 100 | `#FFE6D4` | 선택된 칩, 고른 역 |
| 200 | `#FFC9A6` | 시간표 1명 |
| 300 | `#FFA76F` | 시간표 2명 |
| 400 | `#FF8A3D` | 시간표 3명 |
| 500 | `#FF6A13` | 주 버튼, 진행 막대, 1순위, 마주 얼굴 |
| 600 | `#E85A0A` | 주 버튼 누름 |
| 700 | `#C24A05` | 흰 바탕 위 탠저린 글자, 포커스 |
| 800 | `#933805` | 예비 |

### 잉크와 의미 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 잉크 900 | `#17181A` | 본문 글자, 탠저린 위 글자 |
| 잉크 500 | `#6E6A61` | 보조 글자 |
| 잉크 100 | `#F4F3F0` | 구역 띠(8px), 입력칸 바탕 |
| 흰색 | `#FFFFFF` | 화면 바탕 |
| 성공 | `#177A41` | 완료 |
| 주의 | `#9A6000` | 주의 글자 |
| 위험 | `#B3261E` | 오류, 삭제 |

- 탠저린 500 위 글자는 잉크(대비 6.2:1). 흰 글자는 2.87:1이라 쓰지 않는다.
- 역할 열다섯 쌍의 대비가 모두 4.5:1 이상이어야 토큰이 생성된다.
- 지하철 노선 색(`--color-line-*`)과 지도 색(`--color-map-*`)은 정보 색이다. 브랜드 색과 섞지 않는다. 노선 색은 작은 점으로만 쓰고 그 위에 글자를 올리지 않는다(3호선 주황이 탠저린과 비슷해서).
- 밝은 화면만 쓴다. 다크 값은 아직 없다.

## 4. 글꼴

Pretendard 하나를 쓴다(400, 500, 600, 700, 800).

| 이름 | 크기 | 굵기 | 자간 |
|---|---|---|---|

| h2 | 24px | 800 | -0.03em |

## 5. 마주

**성격:** 모임 총무를 맡은 눈치 빠른 친구. 확인한 사실만 짧게 말하고, 재촉은 하되 누구도 탓하지 않는다.

**생김새:** 역명판을 줄인 탠저린 얼굴, 잉크 눈과 입, 맨 아래 노선 띠와 그 끝의 역 고리. 몸, 볼, 반짝이는 없다.

| 크기 | 판 | 쓰는 곳 |
|---|---|---|
| 24~32px | 소형(띠 없음) | 안내 줄 옆, 머리말 옆 |
| 48~64px | 일반(띠 있음) | 빈 화면, 오류 화면, 링크 미리보기 |
| 로고 | 일반 | 로고 심볼, 앱 아이콘 |

- 화면당 한 번만 나온다. 로고 안의 마주는 세지 않는다.
- AI가 쓴 문장 옆에는 얼굴 대신 작은 "마주" 글자 표시를 붙인다.

| 표정 | 쓰는 때 |
|---|---|
| 기본 | 평소 안내 |
| 생각 중 | 제안을 만드는 동안(눈을 깜빡인다) |
| 기쁨 | 확정했을 때 |
| 미안함 | 오류, 후보가 없을 때 |
| 기다림 | 응답을 기다릴 때 |
| 읽씹당함 | 링크를 읽고 오래 응답이 없을 때 |
| 다 되는 시간 | 모두 되는 시간이 실제로 나왔을 때 |

## 6. 말투

짧은 해요체. 확인한 사실을 먼저 말하고 다음 행동을 제안한다. 기다리는 사람에게 죄책감을 주지 않는다. 사람이 확인하기 전에 확정됐다고 말하지 않는다. 화면마다 큰 제목 한 줄은 지금 상태를 문장으로 쓴다("5명 중 4명이 응답했어요"). 화면별 문구는 `screens/COPY.md`.

## 7. 움직임

움직임은 정보를 전달할 때만 쓴다. 누름 120ms, 열림 200ms, 닫힘 140ms, 숫자와 막대 240ms. 손으로 끄는 것은 스프링. 움직임 줄이기 설정에서는 위치와 크기 변화를 빼고 투명도만 남긴다. 화면별 명세는 `MOTION.md`.

## 8. 하지 않는 것

- 보라색, 보라에서 파랑으로 가는 그라데이션
- 유리 효과(배경 흐림), 발광, 반짝이, 색종이
- 3D 클레이 렌더를 주된 그래픽으로
- 섹션 머리의 이모지
- 모든 덩어리에 같은 둥근 모서리와 그림자를 준 카드 더미. 카드는 고를 수 있는 제안에만
- 화면 중앙의 큰 마주, 한 화면에 마주 둘
- shadcn/ui 기본 모양(회색 테두리, `rounded-md`, Lucide 아이콘)
- 모서리는 8px, 14px, 24px 세 단계만
