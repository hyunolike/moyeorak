# 움직임과 상호작용 명세 (v4)

움직임은 정보를 전달할 때만 쓴다. 반짝이거나 떠다니는 장식은 쓰지 않는다. 라이브러리는 Motion(`motion/react`)이고, 누름과 호버처럼 CSS로 충분한 것은 CSS 전환으로 둔다.

## 토큰

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--duration-press` | 120ms | 누름 반응 |
| `--duration-open` | 200ms | 시트, 펼침이 열릴 때 |
| `--duration-close` | 140ms | 닫힐 때(열릴 때보다 빠르게) |
| `--duration-count` | 240ms | 숫자, 막대가 바뀔 때 |
| `--ease-standard` | cubic-bezier(0.2, 0, 0, 1) | 대부분 |
| `--ease-exit` | cubic-bezier(0.4, 0, 1, 1) | 닫힘 |
| 스프링(손으로 끄는 것) | `{ type: "spring", stiffness: 420, damping: 36 }` | 시트 끌기, 시간표 칸 자리 잡기, 카드 넘기기 |

움직임 줄이기(`prefers-reduced-motion: reduce`)에서는 네 duration이 0ms가 되고, Motion은 `useReducedMotion()`이 참이면 위치와 크기 변화를 빼고 투명도만 바꾼다. 아래 표의 "줄이기" 열이 그 대체다.

## 화면별

| 자리 | 상호작용 | 값 | 줄이기 |
|---|---|---|---|
| 시간표 투표 | 쓸어내리면 칸이 따라 칠해지고, 칠해지는 칸이 1.06배로 커졌다가 자리를 잡는다. 지원하는 기기에서 `navigator.vibrate(8)`. 아래 버튼의 칸 수가 바로 바뀐다 | 스프링, 칸당 한 번 | 크기 변화 없이 색만 바뀜, 진동 없음 |
| 말로 입력하기 | 해석된 칸이 시간 순서로 하나씩 칠해진다. 되돌리기는 거꾸로 지운다 | 칸 사이 30ms, 최대 600ms | 한 번에 칠함 |
| 모임 홈 | 응답 수가 굴러 올라가고 진행 막대가 늘어난다(15초 폴링으로 값이 바뀔 때). 새로 응답한 사람 행이 목록 위에 끼어든다(이전 폴링과 비교, 첫 로드에는 없음) | count 240ms, 행 layout 애니메이션 open 200ms | 숫자와 막대가 바로 바뀜, 행은 투명도만 |
| 마주의 제안 | 카드 두 장을 옆으로 넘긴다. "이유 보기"를 누르면 카드가 제자리에서 펼쳐지고, 장소 카드는 사람별 이동 시간 막대가 늘어난다. 시간 카드는 가능/어려움 칩이 나타난다 | 넘기기 스프링, 펼침 open 200ms, 막대 count 240ms(사람마다 40ms 간격) | 넘기기는 버튼으로만, 펼침과 막대는 즉시 |
| 마주 얼굴 | 제안을 만드는 동안 "생각 중" 얼굴이 2.4초마다 눈을 깜빡인다. 확정하면 "기쁨"으로 바뀐다. 크기와 자리는 그대로 | 깜빡임 150ms | 깜빡임 없음 |
| 확정 | 확인 시트에서 확정하면 약속 카드가 아래에서 올라오고, 날짜와 역 글자가 도장처럼 한 번 1.08배 → 1배로 강조된다. 색종이 효과는 쓰지 않는다 | 올라오기 스프링, 도장 count 240ms | 카드가 바로 나타남 |
| 역 목록 | 역을 고르면 사람별 이동 시간 막대가 그 역 기준으로 늘고 준다. 평균과 최대 시간 숫자도 함께 바뀐다 | count 240ms | 즉시 |
| 시트 | 재촉, 공유, 확인 시트는 아래에서 올라온다. 끌어내려 닫을 수 있고, 손을 뗀 속도를 이어받는다 | 열림 open 200ms, 닫힘 close 140ms, 끌기 스프링 | 투명도만 |
| 복사와 공유 | 복사 버튼 아이콘이 체크로 바뀌었다가 1.6초 뒤 돌아온다. 토스트는 아래 고정 버튼 위(84px)에 뜬다 | 아이콘 교체 press 120ms | 아이콘만 바뀜 |
| 불러오는 중 | 빈 스피너 대신 실제 배치와 같은 모양의 뼈대(skeleton)를 보여 준다. 뼈대는 ink-100 바탕에 ink-200 띠가 1.2초 주기로 지나간다 | 1.2초 반복 | 띠 없이 ink-100 바탕만 |
| 누름 | 버튼, 행, 칩은 누르면 0.98배로 줄었다가 돌아온다 | press 120ms | 없음 |

시간표와 제안 카드는 이 서비스만의 상호작용이라 공들일 자리다. 나머지는 위 규칙 하나로 통일한다.
