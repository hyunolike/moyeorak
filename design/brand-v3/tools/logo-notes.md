# 로고 v3 광학 수정

- `wordmark-ko.svg`, `wordmark-en.svg`는 v2 파일을 바이트 단위로 복사했다. 한글 경로, 사각형 좌표, 영문 윤곽을 수정하지 않았다.
- 심벌의 외곽 `M48 16 … Z` 경로와 우하단 32px 대각 절단은 v2 그대로다. 가로 조합의 원래 배율과 워드마크 위치도 유지했다.
- 얼굴 캡슐 x36 y52 / 88×48 / rx24는 그대로 두고 차가운 흰색을 따뜻한 크림 #FFF1DA로 바꿨다.
- 눈 10×24 막대를 13×16 둥근 눈으로 바꾸고 작은 둥근 하이라이트, 미소, 볼을 캡슐 안에 추가했다. 바깥 실루엣은 바꾸지 않아 기존 심벌 인상을 유지한다.
- 단색은 얼굴 캡슐을 실제 투명 마스크로 뚫는다. 눈 하이라이트는 단색 소형 인쇄에서 생략하고 눈과 입을 한 색으로 남긴다. 흰색 버전은 어두운 면 위에 쓴다.
- 캐릭터는 같은 크림 캡슐과 눈/입 비례를 사용한다. 아바타는 32px에서 입을 읽도록 얼굴을 확대하고 홍시 바탕이 정사각형을 전부 채운다.
