# 모여락 UI 컴포넌트 v3

[전체 상태 시트](components.svg)는 49개 상태를 라이트와 다크 각각에 보여 준다. 목업은 390 × 844 기준이며 Pretendard를 사용한다. `tools/build-ui.mjs`가 이 시트와 6개 화면 SVG를 재생성한다. SVG는 디자인 명세이며 실제 DOM 동작을 구현한 컴포넌트 라이브러리는 아니다.

## 표면과 역할

화면은 따뜻한 중성 바탕 위에 흰 종이를 놓는다. 다크에서도 같은 위계를 유지한다. 숲색은 행동과 선택한 조건에만 쓴다. 선택 면에는 옅은 숲색을 쓰고, 기본 카드 전체를 숲색으로 칠하지 않는다. 마주의 말은 종이 면, 신호 노랑 테두리, 짧은 꼬리와 작은 노랑 배지로 식별한다. 비서의 메시지를 큰 노랑 판으로 만들지 않는다. 홍시색은 캐릭터의 인지를 맡는다.

| 역할 | Light | Dark |
|---|---|---|
| 화면 | `#FAF9F6` | `#24221F` |
| 종이 | `#FFFFFF` | `#312E2A` |
| 본문 | `#202923` | `#FAF9F6` |
| 보조 글자 | `#625D54` | `#CCC6BC` |
| 장식 구분선 | `#E4E0D8` | `#4B4741` |
| 필수 입력 경계 | `#7B7469` | `#A49C90` |
| 행동 | `#176B5B` | `#7DD4B5` |
| 행동 위 글자 | `#FFFFFF` | `#202923` |
| 행동 hover / pressed | `#125749` / `#10483D` | `#A8D9C3` / `#D2EDDF` |
| 선택 면 | `#EAF6F0` | `#103A32` |
| 오류 | `#AD3422` | `#FFBBA8` |
| 비활성 면 / 글자 | `#E4E0D8` / `#625D54` | `#4B4741` / `#CCC6BC` |
| 비서 배지 / 위 글자 | `#F3CF58` / `#44371A` | `#F3CF58` / `#44371A` |

장식 구분선은 필수 입력 경계나 포커스 표시를 대신하지 않는다. 필수 입력 경계와 2px 포커스 링은 별도 역할이다. 다크는 사진을 뒤집거나 원색 캐릭터를 탈색하지 않고 UI 의미 토큰만 바꾼다.

## 크기와 글자

- 간격은 4px 단위를 기본으로 하며 화면 좌우 24px, 카드 안 20px, 조밀한 상태 줄은 16px을 쓴다.
- 버튼 높이 52px, 고정 CTA 56px, 입력 최소 48px. 칩의 시각적 높이는 36px이고 클릭 영역은 최소 44px이다. 시간표 셀도 화면 확대나 스크롤을 허용해 최소 44px 클릭 영역을 확보한다.
- 버튼 radius 16px, 입력 12–16px, 카드 20–24px, 작은 배지는 캡슐이다. 카드에 상시 그림자를 여러 겹 쌓지 않는다.
- 제목은 26–34px / 1.25, 본문 16px / 1.5, 버튼 16px / 24px 650, 보조 12–14px / 1.5다. 상태 시트의 10–11px은 명세 라벨이나 짧은 배지 전용이다. 실제 동작과 오류를 작은 글자로만 전달하지 않는다.
- 모든 인터랙션은 `:focus-visible`에서 외곽 4px 간격의 2px 링을 보인다. 링이 부모의 `overflow: hidden`으로 잘리지 않게 한다. 키보드 포커스가 색상 변화만으로 보이지 않게 하지 않는다.

## 상태 계약

| 컴포넌트 | 시트에 포함한 상태 | 상태별 동작과 접근성 |
|---|---|---|
| Primary / secondary / text 버튼 | 각 default, hover, pressed, focus, disabled, loading | 명시적인 동사 사용. `button` 기본 요소. 처리 중 `aria-busy="true"`와 동작 문구를 유지하고 중복 제출을 막는다. 단순 로딩 표시를 새로운 포커스 대상으로 만들지 않는다. 비활성 사유는 근처 설명에 둔다. |
| 조건 칩 | unselected, selected, disabled, focus | 다중 조건은 `aria-pressed` 토글 버튼, 단일 선택 집합은 라디오를 사용한다. 선택은 체크와 옅은 선택 면을 함께 표시한다. `aria-checked`와 `aria-pressed`를 한 요소에 중복하지 않는다. |
| 참여자 상태 | completed, waiting | 같은 크기 이름 행, 완료 체크와 ‘응답 완료’, 미응답 대시와 ‘기다리는 중’. 친구에게 죄책감을 주는 강조나 경고색을 쓰지 않는다. 진행 인원은 `3 / 4 응답`으로 별도 제공한다. |
| 모임 카드 | default, hover, focus, selected, disabled | 제목, 날짜와 인원, 응답 상태, 진행 방향을 보여 준다. 선택 면과 체크는 탐색 중 선택을 의미한다. 카드 전체가 링크면 내부에 중첩 버튼을 넣지 않는다. 비활성 카드는 확정 등 구체적인 사유를 설명한다. |
| 마주 말풍선 | default, loading, error | 종이 면, 노랑 테두리와 꼬리, 발화 라벨. 오류 시 실패 범위와 복구 행동을 함께 표시한다. 비동기 안내는 `role="status"` / `aria-live="polite"`; 입력을 막는 오류는 해당 입력의 설명에 연결한다. 캐릭터 이미지는 옆 문장이 같은 정보를 제공하면 빈 `alt`를 쓴다. |
| 제안 카드 | default, expanded, selected, loading | 날짜와 시간, 장소, 전원 가능 여부를 나눈다. 펼침은 근거인 이동시간 범위를 보이며 버튼에 `aria-expanded`와 `aria-controls`를 둔다. selected는 확정 전 후보다. 로딩 시 자리만 차지하는 스켈레톤은 `aria-hidden`이며 실제 작업 문구를 읽는다. |
| 시간표 셀 | available, selected, best, unavailable, focus | 기본 가능 시간은 빈 종이 셀, 선택은 옅은 숲색과 체크, 최다 겹침은 노랑과 체크, 불가는 대시로 구분한다. 셀 accessible name에 날짜, 시각과 상태를 모두 넣는다. ‘11월 2일 월요일 18시, 선택됨’처럼 읽는다. 그리드는 방향키 이동, Home/End, Space 선택을 제공하고 날짜 헤더를 연결한다. |
| 텍스트 입력 | empty, focus, filled, error, disabled | placeholder와 별도로 ‘가능한 시간’ 라벨 유지. 오류는 경계선뿐 아니라 원인과 수정 방법을 적고 `aria-invalid` / `aria-describedby` 연결. disabled 사유를 읽을 수 있게 제공한다. |
| 하단 고정 CTA | enabled, disabled, loading | 상단 구분선, 단일 주동작, 아래 safe area. `padding-bottom: env(safe-area-inset-bottom)` 적용. 본문에도 고정 영역만큼 여백을 확보하고 키보드가 올라왔을 때 입력을 가리지 않는다. |

시간표 범례: **빈 셀 = 가능한 시간**, **숲색 체크 = 내가 선택한 시간**, **노랑 체크 = 가장 많이 겹치는 시간**, **대시 = 불가능**, **이중 외곽 링 = 키보드 포커스**. 실서비스에서는 각 상태의 설명을 셀의 접근 가능한 이름에도 제공한다. 최다 겹침과 확정은 같은 의미가 아니다.

## 선택과 확정

‘내 일정’에 자연어를 입력하면 저장 전 시간표 미리보기를 만든다. 사용자가 칸을 고치고 **이 시간으로 저장**을 눌러야 응답이 반영된다. 제안 카드를 고른 상태도 약속이 확정된 상태가 아니다. **이걸로 확정**을 눌렀을 때만 확정 요약 화면과 ‘확정됐어요’를 보여 준다. 시간 입력 완료, 후보 선택, 약속 확정은 서로 다른 이벤트다.

목업의 시간 입력 문구는 ‘담주 평일 저녁 되고 수요일은 빼줘’이며 2026년 10월 30일 기준 다음 주 평일인 11월 2–6일의 저녁을 표시한다. 수요일은 대시로 제외했다. 제안과 확정 화면은 별도의 예시 약속인 ‘11월 1일 일요일 오후 2시 · 홍대입구역’을 보여 준다. 이 예시들은 고정 디자인이며 실제 추천 데이터나 실제 지도 경로를 의미하지 않는다.

## 모션과 오류 복구

버튼 상태 변화는 120ms, 패널과 내용 전환은 180ms ease-out을 상한으로 삼는다. `prefers-reduced-motion: reduce`에서는 위치 이동과 반복 회전을 멈추고 정적인 처리 중 문구를 남긴다. 미응답 참여자를 재촉하는 반복 애니메이션을 쓰지 않는다. 저장 실패 시 편집한 시간표를 보존하고 재시도를 제공한다. 외부 장소 조회 실패가 입력 완료 상태까지 지우지 않게 한다.

## 대비와 전달 범위

대비 원본은 [ui-pairs.json](../tools/ui-pairs.json)이며 `tools/build-ui.mjs`의 토큰과 실제 텍스트 조합에서 추출했다. 계산은 WCAG 상대 휘도식, 일반 글자 AA 4.5:1을 기준으로 한다. 비활성 상태도 읽을 수 있는 조합으로 포함했다. 필수 입력 테두리와 포커스 링은 비텍스트 3:1 기준으로 별도 검증해야 한다. 노랑 경계는 비서의 장식적 표시이며 조작 대상의 유일한 경계가 아니다.

SVG 생성과 텍스트/구조 확인은 이 작업의 검증 범위다. 최종 PNG 렌더, 한글 조판과 3D 이미지 합성 후 시각 검수는 통합 제작 단계에서 수행한다. 캐릭터의 일반 사용자 인지 검사는 실제 사람의 독립 피드백을 받기 전까지 대기 상태다.
